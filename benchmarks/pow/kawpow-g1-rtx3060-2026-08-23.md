## Reproducibility Notes

- The external miner source was pinned and changed only by
  [`0001-gcc13-cstdint.patch`](../../patches/kawpowminer/0001-gcc13-cstdint.patch),
  which adds a missing `<cstdint>` include for GCC 13.
- `AICHAIN_KAWPOW_CXX_FLAGS=-DPTHREAD_STACK_MIN=16384` was required for the
  miner's Boost 1.70 dependency on glibc 2.39.
- `AICHAIN_KAWPOW_COMPUTE=86` targeted the RTX 3060 and avoided obsolete CUDA
  architectures no longer supported by CUDA 12.6.
- Raw miner output, metadata, and telemetry were retained outside the Git
  repository as untrusted run artifacts.
- No pool, wallet, private key, or network mining credential was used.

## Interpretation and Limits

This result proves that the selected KawPoW revision runs reproducibly on one
NVIDIA Ampere GPU and provides a power/thermal baseline for later comparisons.
It does not demonstrate Core-Geth interoperability, network block production,
AMD support, ASIC resistance, economic security, or quantum resistance. The
AMD/OpenCL G1 repeat and the G2 node-integration gate remain open.
