# Orvessian commercial direction — 27 September 2026

> Historical archive — 27 September 2026. Retained for its original scope, not current launch guidance. See the [active documentation](C:/AIChain/docs/README.md).

Proposed monthly/annual workspace subscription with included accepted-event usage and measured overages. Evaluate/Operate/Enterprise are packaging concepts. No numeric prices, allowances, retention commitments or SLA are approved. Earlier fixed pilot/subscription/per-event price bands are retired.

The testnet relayer sponsors Base gas; customers do not need ETH or a native token. Gas is a managed-service cost, not a separate customer wallet requirement. One accepted event is not one model run or one chain transaction. Idempotent retries must not add billable usage; production billing controls still need implementation.

Costs include API validation, private structured-record storage, signatures, batch proofs, Base fees including L1 data, indexing, backups, exports and support. Source conversations/documents/media remain customer-held and are never a custody product. Measured costs and customer value precede commercial release.

Current product: synthetic governance demonstration and private VPS-backed development workspace with signed evidence and Base Sepolia verification. No checkout, public customer onboarding, production service or mainnet availability is implied. Marketplace/usage-intelligence ideas require a separate consent, rights and privacy review; no resale of customer records is enabled.

See [platform baseline](../../../../docs/platform-architecture.md) and [review record](../../../../docs/archive/2026-09-27/superseded-plans/documentation-review-2026-09-27.md). Public website publication is a separate action.
